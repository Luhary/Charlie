# Чарли v0

Чарли (таинственная дама в шляпе) + Dynamic Island + виджеты + команды для Action Button и автоматизаций.

## Картинки Чарли
Лежат в `Shared/CharlieAssets.xcassets/charlie_<имя>.imageset/`:
idle, blink, listening, thinking, speaking_a, speaking_b, surprised, smirk, full (в полный рост, не квадрат).
Новое настроение добавляется файлом в каталог + строкой в `CompanionMood` и `CharlieAvatar`.

Когда она показывается:
- idle + моргание: в покое
- listening / thinking / speaking: слушает / ждёт ответ / отвечает (рот чередуется A и B)
- smirk: пару секунд после того, как договорила
- surprised: если что-то пошло не так (нет ключа, ошибка сети)
- full: средний виджет на домашнем экране

## Карты
Голосом или текстом: «как добраться до улицы Ленина 5», «построй маршрут пешком до вокзала», «где ближайший строительный».
Открывается в Яндекс Картах (по умолчанию), Apple или Google — выбор в ⚙️. Местоположение определяется один раз на команду, в фоне не отслеживается.

## Календарь
Скажи: «Чарли, я хочу 7 ноября с часу до трёх дня сделать лабораторную Атнабаева» или «завтра в 15:00 созвон». Чарли покажет, что поняла (название, дата с годом, время) и спросит «Записать?». После подтверждения событие появляется в календаре.
Дату и время разбирает твоя нейронка по API-ключу (для этого нужен ключ). Доступ к календарю «только запись»: Чарли не читает твои события.

## Нейронки
В ⚙️ выбери провайдера: OpenRouter (бесплатные модели :free), Google Gemini (бесплатный тариф, из России нужен VPN), любой OpenAI-совместимый сервис или Anthropic. У каждого свой ключ и модель. Кнопка «Выбрать из списка» показывает модели, доступные прямо сейчас (на OpenRouter только бесплатные).
Бесплатные тарифы имеют лимиты, а запросы на них могут использоваться провайдером для обучения. Команды про календарь и будильники тоже тратят по одному запросу на разбор фразы.

## Заметки, будильники, звонки, блокировка
- **Заметка:** «Чарли, запиши заметку: купить хлеб». Лежит в приложении (кнопка 📝 вверху), удаляется свайпом, оттуда можно отправить в Заметки Apple (долгое нажатие → Поделиться).
- **Будильник и таймер:** «разбуди меня в 7 утра», «таймер на 10 минут». Будильник покажется на подтверждение. На iOS 26 это настоящий системный будильник (звонит и в беззвучном режиме).
- **Звонок:** «позвони маме», «позвони Ивану Петрову», «позвони на номер 8…». Контакт ищется среди твоих; если подходит несколько, предложит выбрать. iOS сам спросит «Позвонить?».
- **Блокировка экрана:** «заблокируй экран» или «заблокируй экран через 2 минуты». Приложениям iOS запрещает блокировать экран, поэтому Чарли запускает твою «Команду»:
  1. Приложение «Команды» → «+» → назови команду **Заблокировать Чарли** (или другое имя, тогда впиши его в ⚙️).
  2. Добавь действие «Ждать» → количество секунд выбери переменной **Ввод команды**.
  3. Добавь действие **Заблокировать экран**.
  Задержка работает, пока «Команды» остаются запущенными, поэтому для долгих задержек она ненадёжна.

## Сборка (Windows → GitHub → iPhone)
1. Залей папку в репозиторий GitHub (ветка `main`): `git init`, `git add .`, `git commit -m init`, `git push`.
   Папку `.github` обязательно — в ней сборка.
2. Вкладка Actions → дождись зелёной галочки (5–10 мин) → внизу страницы запуска скачай артефакт `Companion-ipa`, внутри `Companion.ipa`.
3. iPhone по USB → iloader → войти бесплатным Apple ID → установить `Companion.ipa`.
4. На iPhone: Настройки → Основные → VPN и управление устройством → довериться; включить Режим разработчика.

## Настройка на телефоне
- ⚙️ в приложении: вставь API-ключ.
- Action Button: Настройки → Action Button → Команда → «Слушать Чарли».
- Реакция на TikTok: Команды → Автоматизация → Приложение → TikTok «Открыто» → «Реакция на открытое приложение» (TikTok, 5) → «Запускать сразу».
- Виджет: долгое нажатие на домашнем экране → «+» → Чарли (маленький или средний).
