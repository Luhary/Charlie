# Чарли v0

Чарли (таинственная дама в шляпе) + Dynamic Island + виджеты + команды для Action Button и автоматизаций.

## Картинки Чарли
Лежат в `Shared/CharlieAssets.xcassets/charlie_<имя>.imageset/`:
idle, blink, listening, thinking, speaking_a, speaking_b, surprised, smirk, full (в полный рост, не квадрат).
Новое настроение добавляется файлом в каталог + строкой в `CompanionMood` и `CharlieAvatar`.

Когда она показывается:
- idle + моргание: в покое
- listening / thinking / speaking: слушает / ждёт ответ / отвечает (рот чередуется A и B)
- smirk: пару секунд после того, как договорила
- surprised: если что-то пошло не так (нет ключа, ошибка сети)
- full: средний виджет на домашнем экране

## Карты
Голосом или текстом: «как добраться до улицы Ленина 5», «построй маршрут пешком до вокзала», «где ближайший строительный».
Открывается в Яндекс Картах (по умолчанию), Apple или Google — выбор в ⚙️. Местоположение определяется один раз на команду, в фоне не отслеживается.

## Сборка (Windows → GitHub → iPhone)
1. Залей папку в репозиторий GitHub (ветка `main`): `git init`, `git add .`, `git commit -m init`, `git push`.
   Папку `.github` обязательно — в ней сборка.
2. Вкладка Actions → дождись зелёной галочки (5–10 мин) → внизу страницы запуска скачай артефакт `Companion-ipa`, внутри `Companion.ipa`.
3. iPhone по USB → iloader → войти бесплатным Apple ID → установить `Companion.ipa`.
4. На iPhone: Настройки → Основные → VPN и управление устройством → довериться; включить Режим разработчика.

## Настройка на телефоне
- ⚙️ в приложении: вставь API-ключ.
- Action Button: Настройки → Action Button → Команда → «Слушать Чарли».
- Реакция на TikTok: Команды → Автоматизация → Приложение → TikTok «Открыто» → «Реакция на открытое приложение» (TikTok, 5) → «Запускать сразу».
- Виджет: долгое нажатие на домашнем экране → «+» → Чарли (маленький или средний).
